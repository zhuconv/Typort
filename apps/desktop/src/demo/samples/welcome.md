# Welcome to Typort

You're looking at **Typort's editor**, running entirely in your browser.

In the real app, `typort open <file>` on any server you've SSH'd into opens
that file *here* — in a native window on your own machine — and edits save
straight back over the tunnel.

## Try it

- Pick a **language** from the menu in the top-left to load a sample file.
- Edit anything. This Markdown file renders *as you type*.
- Code files open in a real editor — Monaco, with Shiki highlighting.
- On code files, switch the **theme** and **font size** in the top bar.

## Three ways to open a file

| File type        | Editor              | What you get          |
| ---------------- | ------------------- | --------------------- |
| `.md`            | open-typora         | WYSIWYG, like Typora  |
| `.html`          | preview **+** source | rendered or editable |
| everything else  | Monaco + Shiki      | real code editing     |

> Nothing here is uploaded anywhere. Edits stay in this browser tab — hit
